# AI 影片工廠評估規劃

## 評估目的

確認影片是否符合原始一句話、是否適合平台發布，並建立可改善的品質紀錄。

## 評估項目

- 腳本是否清楚
- Hook 是否夠強
- 分鏡是否合理
- 圖片是否符合內容
- 旁白是否自然
- 字幕是否易讀
- 節奏是否適合平台
- 影片是否可直接發布
- 是否有版權或授權風險

## 平台評估重點

### Shorts

- 前 3 秒是否吸引人
- 字幕是否容易掃讀
- 影片是否適合直式觀看

### YouTube

- 標題是否清楚
- 內容是否完整
- 是否有搜尋價值
- 是否需要縮圖

### TikTok

- 開頭是否夠直接
- 節奏是否夠快
- 是否有互動或留言誘因

### Instagram

- 畫面是否有品牌感
- 是否適合 Reels 觀看
- 字幕是否乾淨不干擾主體
- 是否適合轉成貼文或限動素材

## 評分方式

```text
5 = 可直接發布
4 = 小幅修改後可發布
3 = 方向正確但需要重剪
2 = 部分可用但品質不足
1 = 不符合需求
```
