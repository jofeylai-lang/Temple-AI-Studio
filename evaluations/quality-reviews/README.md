# Quality Reviews

Purpose:

Store structured Temple AI Studio quality reports.

Use this folder for:

- video export quality reports
- subtitle quality reports
- Emma identity checks
- voice consistency checks
- playback validation
- targeted regeneration reports

Initial shared checker:

```text
scripts/temple_ai_studio/quality_check.py
```

Do not store private source photos, raw customer content, API keys, tokens or generated videos here.
