# scripts/video-factory

AI 影片工廠的腳本、旁白稿、分鏡文字與平台文案集中放在這裡。

## 日期分類

```text
scripts/video-factory/YYYY/MM/DD/
```

## 建議檔名

```text
YYYYMMDD_HHMMSS_video-factory_task-id_script_v01.md
```

## 腳本格式

```text
# Video Script

task_id:
created_at:
source_input:
target_platforms:
title:
hook:
main_points:
voiceover:
scene_list:
call_to_action:
notes:
```

## 分鏡格式

每個分鏡建議包含：

- scene_id
- 畫面描述
- 圖片 Prompt
- 旁白
- 字幕
- 秒數
- 轉場
- 音效或音樂建議
