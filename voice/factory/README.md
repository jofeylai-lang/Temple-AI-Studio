# voice/factory

AI 影片工廠的旁白音檔與聲音 metadata 集中放在這裡。

## 子資料夾

- `narration/`：旁白音檔
- `metadata/`：聲音生成紀錄

## 日期分類

```text
voice/factory/narration/YYYY/MM/DD/
voice/factory/metadata/YYYY/MM/DD/
```

## 旁白命名規則

```text
YYYYMMDD_HHMMSS_video-factory_task-id_narration_v01.wav
```

## 旁白 metadata 欄位

```text
task_id:
created_at:
voice_name:
language:
tone:
speed:
source_script:
output_file:
status:
notes:
```
