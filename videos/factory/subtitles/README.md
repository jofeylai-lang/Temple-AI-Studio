# 字幕規格

字幕檔放在此資料夾，並依日期分類。

## 日期分類

```text
videos/factory/subtitles/YYYY/MM/DD/
```

## 建議格式

- `.srt`：影片平台常用字幕
- `.vtt`：網站與網頁播放器常用字幕
- `.txt`：純文字備份與人工審稿

## 命名規則

```text
YYYYMMDD_HHMMSS_video-factory_task-id_subtitles_v01.srt
```

## 字幕原則

- 每句不要太長
- 保留口語節奏
- 重要關鍵字可獨立成句
- Shorts 與 TikTok 字幕應更短、更有節奏
- YouTube 可保留較完整句子
