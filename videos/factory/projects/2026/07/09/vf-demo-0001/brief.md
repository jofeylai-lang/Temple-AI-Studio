# Image Factory Demo Video Brief

Project ID: vf-demo-0001
Date: 2026-07-09
Format: Vertical short demo
Target platforms: Shorts, Instagram Reels, TikTok

## Goal

Create a short visual demo showing how Jofey AI Studio can turn one sentence into an organized image generation workflow.

## Core Message

One sentence can become a complete image production record: prompt, image, date folder, metadata, and reusable history.

## Visual Direction

- Warm coastal AI Studio identity
- Friendly virtual host
- Clean interface-like visual cards
- Bright white, ocean blue, soft silver, warm sand
