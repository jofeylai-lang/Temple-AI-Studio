# prompts/image-factory

AI 圖片工廠的 Prompt 紀錄集中放在這裡。

## 日期分類規則

```text
prompts/image-factory/YYYY/MM/DD/
```

## Prompt 紀錄命名規則

```text
YYYYMMDD_HHMMSS_image-factory_task-id_prompt_v01.md
```

範例：

```text
20260709_103000_image-factory_if-000001_prompt_v01.md
```

## Prompt 紀錄格式

```text
# Image Factory Prompt Record

task_id:
created_at:
source_input:
intent:
style:
aspect_ratio:
final_prompt:
negative_prompt:
metadata_file:
output_file:
review_status:
notes:
```

## 記錄原則

- 原始輸入必須保留
- 整理後 Prompt 必須保留
- 若有修改 Prompt，使用新版本號
- 不覆蓋舊版本
- 每張圖片都要能追到它的 Prompt
