# prompts/video-factory

AI 影片工廠的 Prompt 紀錄集中放在這裡。

## 日期分類

```text
prompts/video-factory/YYYY/MM/DD/
```

## Prompt 類型

- `script`：腳本生成 Prompt
- `storyboard`：分鏡生成 Prompt
- `image`：畫面圖片 Prompt
- `voice`：旁白生成 Prompt
- `subtitle`：字幕生成 Prompt
- `platform`：平台文案與輸出調整 Prompt

## 建議檔名

```text
YYYYMMDD_HHMMSS_video-factory_task-id_prompt-type_v01.md
```

範例：

```text
20260709_104000_video-factory_vf-000001_script_v01.md
20260709_104000_video-factory_vf-000001_image_v01.md
```

## 紀錄原則

- 保留原始一句話
- 保留每個階段實際使用的 Prompt
- 不覆蓋舊版本
- 每個輸出檔都要能追回 Prompt
