# Terminology V1

Product: Temple Product Video Generator

Date: 2026-07-23

Status: V1 Ready Candidate

## Purpose

This document standardizes product terminology across all V1 documents.

## Approved Names

Temple AI Studio:

The operating system for AI content production.

Temple Product Video Generator:

The first application built on top of Temple AI Studio.

Product Video:

A short vertical 9:16 product video package prepared for manual posting.

Product Library:

The product management area for product names, descriptions, selling points, photos, and materials.

Create Video:

The screen and workflow step where product, materials, Chinese description, platform, tone, length, and CTA are prepared.

Generation Progress:

The step where AI prepares story, scenes, narration, subtitles, visual direction, caption, thumbnail suggestion, and preview.

Preview:

The reviewable draft before export.

Scene Detail:

The focused area for editing or regenerating one scene.

Export:

The final preparation step for MP4, caption, subtitles, thumbnail suggestion, metadata, and file location.

## Approved Status Terms

Draft:

Work exists but has not been approved.

Needs Revision:

One or more quality checks failed or the user requested changes.

Approved:

The user accepted the preview and content package.

Exported:

Final MP4 and supporting files are available.

Failed:

Generation or export failed, but recovery data is preserved.

Archived Candidate:

Historical or obsolete work that should be preserved but not used as active V1 workflow.

## Terms To Avoid

Avoid using these as active V1 scope:

- Universal AI engine
- Auto publishing
- Full-body human animation
- Voice cloning
- User accounts
- Billing
- Multi-product batch generator
- Advanced video editor

## Definition of Done

Terminology V1 is complete when all V1 documents use the approved names and statuses consistently.
