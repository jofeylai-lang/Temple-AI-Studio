## Release Gate

V1 can move to CEO Review when:

1. All required V1 documents exist.
2. Naming is consistent.
3. No critical documentation corruption remains in V1 docs.
4. Product workflow is coherent.
5. Data model supports the workflow.
6. Validation rules match quality checklist.
7. Acceptance test plan is complete.
8. Remaining risks are known and non-blocking.
