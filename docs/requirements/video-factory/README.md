# AI 影片工廠需求設計

## 核心流程

```text
一句話
↓
生成腳本
↓
生成圖片
↓
生成旁白
↓
生成字幕
↓
生成影片
↓
輸出 Shorts
↓
輸出 YouTube
↓
輸出 TikTok
↓
輸出 Instagram
```

## 專案目標

AI 影片工廠的目標是把一個簡短想法轉換成可發布的多平台影片資產。

每次任務都應留下完整紀錄，包含：

- 原始一句話
- 影片腳本
- 分鏡與畫面 Prompt
- 圖片素材
- 旁白文字
- 旁白音檔
- 字幕檔
- 影片輸出檔
- 平台版本
- Instagram 版本
- metadata
- 品質檢查紀錄

## 第一階段範圍

先完成設計與資料管理規格，不立即加入程式碼、不串接 API、不自動生成影片。

第一階段包含：

- 規劃完整工作流
- 建立資料夾結構
- 建立命名規則
- 建立 metadata 規格
- 建立腳本格式
- 建立旁白與字幕規格
- 建立平台輸出規格

## 未來可接入能力

- 圖片生成模型
- 語音生成模型
- 字幕產生工具
- 影片剪輯工具
- Telegram Bot
- 網站介面
- YouTube 上傳流程
- TikTok 發布流程
- 批次產生短影音

## 主要輸出格式

### Shorts

- 比例：9:16
- 建議長度：15 到 60 秒
- 目的：快速吸引注意、短影音觸及

### YouTube

- 比例：16:9 或 9:16，依內容形式決定
- 建議長度：短版 1 分鐘內，長版可擴充
- 目的：搜尋、訂閱、長期內容資產

### TikTok

- 比例：9:16
- 建議長度：15 到 60 秒
- 目的：節奏快速、強 Hook、強視覺記憶點

### Instagram

- 比例：9:16 為主，必要時保留 1:1 或 4:5 版本
- 建議長度：15 到 90 秒
- 目的：Reels 觸及、品牌形象、社群互動與內容再利用
