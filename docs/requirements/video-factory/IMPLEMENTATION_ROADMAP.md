# AI 影片工廠實作路線圖

## Phase 1：設計完成

狀態：進行中

目標：

- 完成需求文件
- 完成工作流文件
- 完成影片資料夾規則
- 完成腳本格式
- 完成旁白與字幕規格
- 完成平台輸出規格
- 完成 metadata 規格

## Phase 2：手動製作流程

目標：

- 使用一句話建立影片 brief
- 手動產生腳本
- 手動整理分鏡
- 手動放入圖片
- 手動放入旁白
- 手動放入字幕
- 手動輸出平台版本

此階段不需要程式。

## Phase 3：半自動製作流程

目標：

- 自動建立任務資料夾
- 自動建立腳本模板
- 自動建立 metadata 模板
- 自動建立平台發布包
- 圖片、旁白、影片仍可手動加入

此階段可開始加入簡單自動化，但需另外確認。

## Phase 4：全自動影片生成

目標：

- 一句話輸入
- 自動產生腳本
- 自動產生圖片
- 自動產生旁白
- 自動產生字幕
- 自動合成影片
- 自動輸出 Shorts、YouTube、TikTok、Instagram 版本

需要先決定：

- 使用哪個圖片模型
- 使用哪個語音模型
- 使用哪個影片合成工具
- 是否需要雲端運算
- 是否需要成本控管
- 是否接 Telegram 或網站

## Phase 5：產品化

目標：

- Telegram 一句話產影片
- 網站影片工廠介面
- 任務佇列
- 批次產片
- 影片搜尋
- 自動發布
- 成效追蹤
