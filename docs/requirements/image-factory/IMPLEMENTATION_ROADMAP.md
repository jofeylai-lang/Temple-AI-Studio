# AI 圖片工廠實作路線圖

## Phase 1：規劃完成

狀態：進行中

目標：

- 完成需求文件
- 完成工作流文件
- 完成儲存規則
- 完成 metadata 規格
- 完成 Prompt 紀錄格式

## Phase 2：本機手動流程

目標：

- 手動輸入一句話
- 手動整理 Prompt
- 手動放入圖片
- 手動建立 metadata
- 手動建立 Prompt 紀錄

此階段仍不需要程式。

## Phase 3：半自動流程

目標：

- 自動建立日期資料夾
- 自動建立 metadata 模板
- 自動建立 Prompt 紀錄模板
- 圖片仍可手動放入

此階段可開始加入簡單自動化，但需另行確認。

## Phase 4：全自動圖片生成

目標：

- 一句話輸入
- 自動呼叫圖片模型
- 自動儲存圖片
- 自動寫入 metadata
- 自動建立 Prompt 紀錄

需要先決定：

- 使用哪個圖片模型
- 是否使用 API
- 圖片尺寸與比例
- 是否需要成本控管
- 是否要接 Telegram 或網站

## Phase 5：產品化

目標：

- Telegram Bot
- 網站介面
- 任務佇列
- 圖片搜尋
- 批次生成
- 權限管理
- 成本報表
