# AI 圖片工廠需求規劃

## 核心功能

使用者輸入一句話，系統自動完成以下流程：

```text
一句話
↓
整理成圖片生成 Prompt
↓
生成圖片
↓
依日期存到 images
↓
產生 metadata
↓
建立 Prompt 紀錄
↓
可供日後搜尋、追蹤、重做與改版
```

## 第一階段目標

- 建立標準輸入格式
- 建立圖片輸出命名規則
- 建立日期分類規則
- 建立 metadata 欄位
- 建立 Prompt 紀錄格式
- 保留未來接入圖片模型、自動化工具、Telegram 或網站介面的空間

## 使用者輸入

最小輸入：

```text
一位未來感 AI 女助理站在霓虹城市中
```

未來可擴充輸入：

```text
主題：AI 女助理
風格：電影感、未來感、霓虹城市
比例：16:9
用途：網站首頁
品質：高
禁止：模糊、低解析、文字錯誤
```

## 輸出內容

每次生成應產生：

- 圖片檔
- metadata 檔
- Prompt 紀錄
- 生成批次紀錄
- 如有失敗，保留失敗原因

## 不在第一階段處理

- 不立即串接實際圖片生成 API
- 不立即建立網站介面
- 不立即建立 Telegram Bot
- 不立即處理付費、帳號、權限、雲端部署

## 後續可擴充方向

- Telegram 一句話生成圖片
- 網站上傳與生成介面
- 多模型切換
- 圖片品質評分
- 自動重試
- 自動生成多尺寸版本
- 自動生成社群貼文文案
