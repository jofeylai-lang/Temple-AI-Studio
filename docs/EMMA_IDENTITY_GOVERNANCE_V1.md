# Emma Identity Governance V1

Status: Active Standard

Date: 2026-07-24

Authority:

- `TEMPLE_AI_CONSTITUTION.md`

## Purpose

Protect Emma as a permanent Temple AI Studio identity before building Emma generation workflows.

## Permanent Identity

Emma must preserve:

- same face
- same body
- same voice
- same identity
- core character continuity

## Mutable Styling

Emma may change:

- clothing
- hairstyle
- accessories
- scene
- pose
- expression
- lighting
- camera language

## Required Source Material

Emma production cannot become reliable without approved source material.

Required future material:

- face reference
- body reference
- voice reference
- approved identity description
- approved age/style/business use rules
- rejected examples showing what is not Emma

If required Emma training/source material is unavailable, Codex must stop and request CEO material rather than invent permanent identity.

## Quality Gates

Emma outputs must validate:

- face consistency
- body consistency
- voice consistency
- no unwanted identity drift
- natural expression
- natural motion
- scene/style change without identity change

## Provider Benchmark Candidates

Candidate workflows must be benchmarked before adoption:

- LivePortrait
- MuseTalk
- ComfyUI character workflows
- GPT-SoVITS for voice
- future local or free alternatives

Paid identity or voice providers require CEO approval.

## Regeneration Rule

If Emma identity fails:

1. Preserve approved script.
2. Preserve approved storyboard.
3. Preserve approved non-Emma assets.
4. Regenerate only Emma visual, motion or voice component.
5. Re-run identity quality gate.

## Definition Of Done

Emma Identity Governance V1 is complete when future Emma workflows can distinguish permanent identity from mutable styling and know when CEO source material is required.
