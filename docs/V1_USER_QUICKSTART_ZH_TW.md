# Temple Product Video Generator V1 快速開始

## 啟動

雙擊：

```text
D:\AI\Jofey AI Studio\apps\temple-product-video-generator\start.bat
```

瀏覽器會開啟：

```text
http://127.0.0.1:4173
```

## 建立影片

1. 到「商品資料庫」建立商品。
2. 上傳至少一張商品照片。
3. 到「建立影片」輸入繁體中文需求。
4. 按「產生腳本、場景與預覽影片」。
5. 到「影片預覽」播放 MP4。
6. 到「場景細節」編輯或重生單一場景。
7. 批准影片。
8. 到「匯出」輸出完整內容包。

## 輸出位置

```text
apps/temple-product-video-generator/data/exports/<project-id>/
```

## 注意

- 不需要付費 API。
- 沒有 ComfyUI 也能輸出 MP4。
- 沒有 TTS 時會輸出無旁白音訊版本，但旁白稿和字幕仍會產生。
